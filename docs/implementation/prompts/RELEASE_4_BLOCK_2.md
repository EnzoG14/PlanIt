## Implementación exigida

Rango **A02 aprobado** `[inicio Argentina 00:00, día posterior al final 00:00)` sobre `starts_at` únicamente; no usar `ends_at` para determinar coincidencia; fecha única completa; impedir `desde > hasta`; al limpiar no borrar criterios ajenos. Testear inicio/fin de día y hora de navegador distinta de AR.
2. Añadir UI fecha única/rango y control radio km usando radios técnicos propuestos en D02 (p. ej., 5/10/25/50/100 km y Sin límite; registrar opción final sin confundirla con A01 ya aprobada). Si GPS falla o se deniega, usar **centro del mapa como alternativa aprobada A01** sin otro paso obligatorio, indicando visiblemente «Centro del mapa». El centro inicial Buenos Aires es una posición cartográfica, NUNCA «Tu ubicación». Al mover mapa, recalcular con un comportamiento consistente y evitar saltos; si no hay centro ni GPS, indicar que no es posible aplicar distancia.
3. Calcular distancia geográfica real de gran círculo con validación en SQL: radio finito y >0, lat/lon válidas, km consistentes; prefiltrar bounding box razonable y validar tras Haversine; contemplar cruzar antimeridiano si afecta bbox. PostGIS es opcional/no introducir por defecto.
4. Aplicar **A03 sin pantalla de búsqueda nueva**; coordinar `MapPage` (`MapBounds`, viewport, `discover_public_events`) con `/home`: activar o quitar filtros sin perder el resto, ordenar resultados, paginar lista por cursor y manejar límite/cluster mapa con aviso. Evitar doble fuente de verdad y race al mover el mapa. Resolver intención del usuario cuando cambia centro con radio activo.
5. Preservar interacción de marcadores, links a detalle, foto/placeholder y estados mapa vacío, error y geolocalización denegada. Seguir el collage R4 sin controles `gratuitos`/favoritos.
